GhostShell is a haunted terminal companion that observes your command history, Git activity, and coding mistakes, translating them into eerie, intelligent commentary from a fictional ghost dwelling inside your machine.

---

## 🔮 Phase 1 Overview

Phase 1 establishes the terminal foundation, visual aesthetics, command control subsystem, and modular engine architecture:

- 🟢 **Phosphor CRT Terminal UI:** High-contrast retro green phosphor styling (`#00FF66`, `#39FF14`), spectral cyan highlights (`#00F0FF`), and deep dark panels powered by [Rich](https://github.com/Textualize/rich).
- ⚡ **Haunted Boot-Up Animation:** Simulated CRT electron grid alignment and spectral frequency synchronization on startup (with instant `--no-animation` bypass).
- 📜 **Spectral Grimoire (Slash Commands):** Built-in command registry supporting `/help`, `/clear`, `/quit`, `/exit`, `/status`, and `/about`.
- 🧬 **Standalone Placeholder Response Engine:** Operates without requiring an LLM during UI development. Accurately calculates character/word counts, estimated token usage, and conduit latency while explicitly displaying UI Dev mode diagnostics.
- 🛡️ **Zero-Execution Security Sandbox:** GhostShell **never** executes commands supplied by the user or generated by AI. All transmissions are safely ingested as conversational prompts.
- 🪟 **Windows PowerShell Compatibility:** Fully optimized for Windows Terminal and PowerShell, including graceful handling of `Ctrl+C` (`KeyboardInterrupt`), `EOFError`, and dynamic terminal resizing.

## 🚀 Windows PowerShell Setup Instructions

### 1. Prerequisites
- **Python 3.10+** (Tested on Python 3.10 through 3.14)
- **Windows PowerShell** or **Windows Terminal** (recommended for full 24-bit TrueColor support)
- **Git**

### 2. Clone and Navigate
```powershell
git clone https://github.com/RudraBhullar/GhostShell.git
cd GhostShell
```

### 3. Create and Activate Virtual Environment
```powershell
# Create a virtual environment
python -m venv venv

# If PowerShell script execution is restricted on your machine, enable it for this process:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

# Activate the virtual environment
.\venv\Scripts\Activate.ps1
```

### 4. Install Dependencies
```powershell
pip install -r requirements.txt
```

### 5. Launch GhostShell
```powershell
# Standard launch with boot-up sequence
python main.py

# Or launch immediately bypassing animation
python main.py --no-animation
```

### 6. CLI Flags & Options
```powershell
# Display version
python main.py --version

# Skip startup boot animation
python main.py --no-animation

# Run self-test diagnostics and print status
python main.py --diagnostics

# Show help
python main.py --help
```

## 🛡️ Security Model

In strict accordance with the challenge guidelines:
1. **Never Execute User or AI Commands:** GhostShell will never invoke `subprocess`, `os.system`, `exec`, `eval`, or shell interpreters on user inputs or assistant responses.
2. **Hardcoded Containment Flag:** `GhostConfig.allow_command_execution` is immutable and hardcoded to `False`. Attempting to alter it at runtime raises an immediate `ValueError`.
3. **Proactive Command Detection:** If a user types common shell command prefixes (e.g., `ls`, `dir`, `rm`, `cat`), GhostShell warns the user that arbitrary execution is disabled and treats the input strictly as a conversational query.
